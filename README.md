# Portfolio

Darpan Dahal's personal portfolio. React + Vite, plain CSS design tokens, deployed free on GitHub Pages.

## Develop

```
npm install
npm run dev
```

## Content

All copy, projects, skills, and contact info live in one place: `src/data/portfolio.js`. Placeholders that still need real values are listed at the top of that file.

## Deploy

Push to `main`. The workflow in `.github/workflows/deploy.yml` builds the site and publishes it to GitHub Pages automatically. Pages must be set to deploy from **GitHub Actions** in the repo settings (Settings → Pages → Build and deployment → Source).

Live at `https://Beast-1.github.io/`.
